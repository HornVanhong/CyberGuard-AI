# Khmer Voiceover Audio Slot

Drop your generated or recorded Khmer voiceover MP3 here:
`public/audio/voiceover-khmer.mp3`

When this file is present, Remotion's `<Audio />` component automatically plays it, synchronized across the full 30 seconds (900 frames) of the video!
Currently, a silent 30-second placeholder is placed here so the video renders without errors until your real audio file is dropped in.
